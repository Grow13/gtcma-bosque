## 1. Detección de hiperventilación / agitación respiratoria

**Origen:** Conversación sobre análisis de la onda PPG (ARF).

**Descripción:**  
El anillo podría analizar la variabilidad del pulso para estimar si la persona respira de forma acelerada, superficial o irregular (hiperventilación leve). También podría detectar estados de calma profunda.

**Señales posibles:**
- Ritmo cardíaco acelerado + variabilidad respiratoria alterada → posible agitación.
- Ritmo cardíaco lento + variabilidad clara → calma, coherencia.

**Retroalimentación:**
- Vibración suave (aviso consciente).
- Cambio de color del LED del anillo:
  - **Rojo oscuro / azulado** → estado poco saludable, baja saturación de oxígeno, latidos irregulares.
  - **Verde suave** → calma, sincronía disponible.

**Ética:**
- No diagnosticar, solo sugerir.
- No transmitir sincronía si el estado es muy alterado.

**Estado:** 📌 Guardado para después del prototipo básico.
